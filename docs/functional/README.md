## What is Mystery Date?

Mystery Date (*Cita Misteriosa* in Spanish) is a web application that lets one person plan a surprise date for their partner. The surprise is hidden behind a series of riddles. The host creates the experience, generates a shareable link, and sends it to the guest, who unlocks the reveal by solving each clue in order. No account or login is required.
