# Language Support

The application supports **English** and **Spanish**. Users can switch languages at any time from any page using the language toggle in the header.

---

## Behavior

- The selected language is saved to the browser's local storage and restored on subsequent visits.
- All UI text (labels, buttons, messages, hints, errors) is displayed in the selected language.
- The experience **content** (title, teaser, riddle prompts, success messages, surprise text) is always in the language the host originally wrote it — the language toggle does not translate user-authored content.

---

## Language Options

| Code | Language | Locale |
|------|----------|--------|
| `en` | English | en-US |
| `es` | Spanish | es-419 |

Dates and times are also formatted according to the selected locale.
