# Guest: Experience Flow

**Route:** `/play?data=<payload>`

The guest opens the shared link and solves riddles in order to unlock the final surprise reveal.

---

## Opening the Link

When the guest navigates to the shared URL, the application decodes the experience from the URL payload.

### Valid Link

If the link is valid, the full experience page is shown with:

- The experience **title** and **teaser**.
- The **scheduled date and time**.
- The **starting location** (only if the host provided one).
- A **progress tracker** showing each clue step and the final surprise step.
- A **grid of riddle cards**.

The experience is also saved to the guest's local device so progress persists across sessions.

### Broken or Missing Link

If the URL payload is missing, malformed, or corrupted, a friendly error screen is shown. It explains that the link needs to be regenerated by the host and offers a button to navigate to the home page.

---

## Solving Riddles

Riddles must be solved **in order**. The guest cannot skip ahead to a later clue.

### Riddle Card States

| State | Description |
|-------|-------------|
| **Current** | The active riddle. Shows the prompt and an answer input field. |
| **Solved** | A previously solved riddle. Shows the success message (or a default confirmation). |
| **Locked** | A future riddle. Blocked until all prior clues are solved. Shows a message directing the guest to solve the previous clue first. |

### Submitting an Answer

The guest types their answer into the input field and submits the form.

**Answer matching rules:**
- Case-insensitive (`Library` = `library`).
- Punctuation-insensitive (punctuation marks are stripped before comparison).
- Extra whitespace is normalized.
- Only letters, numbers, and spaces are compared.

The hint "Punctuation and capitalization do not affect your answer" is shown beneath the input field.

### Answer Outcomes

| Outcome | What happens |
|---------|--------------|
| **Correct** | The riddle is marked as solved. The next riddle becomes active. The success message (or default) is displayed. |
| **Incorrect** | An error message is shown on the card. The guest may try again as many times as needed. |
| **Empty submission** | A prompt asks the guest to write an answer before submitting. |

---

## Progress Tracker

A step-by-step progress bar is always visible showing:

- One step per riddle (e.g., Clue 1, Clue 2, Clue 3...).
- A final **Surprise** step.

Each step shows its status: **Locked**, **Current**, or **Complete**.

---

## Progress Persistence

The guest's progress — which riddles have been solved and the current position — is saved to the browser's local storage. If the guest closes the browser and returns to the same link later, their progress is restored automatically.

---

## Unlocking the Final Surprise

Once the guest solves all riddles, the final surprise card replaces the riddle grid and is revealed with a celebration animation. The reveal card shows:

- The **final surprise text** written by the host.
- The **final surprise location** (only if the host provided one).
- The **scheduled date and time**.
- A warm closing message.

The surprise cannot be unlocked until every riddle has been solved.
